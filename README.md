# 유튜브 재생목록 검색기

유튜브(YouTube) 재생목록 페이지와 시청 화면의 재생목록 사이드바에 검색창을 추가해,
재생목록 안에 있는 동영상을 제목으로 실시간 검색/필터링할 수 있게 해주는 크롬 확장 프로그램입니다.

## 주요 기능

- 재생목록 페이지(`youtube.com/playlist?list=...`)에 검색창 추가
- 동영상 시청 화면의 재생목록 사이드 패널(`youtube.com/watch?v=...&list=...`)에도 검색창 추가
- 입력한 검색어(공백으로 구분된 여러 단어 모두 포함하는 AND 검색)로 동영상 목록을 즉시 필터링
- 몇 개의 동영상이 검색되었는지 표시 (`12 / 340개 표시`)
- 스크롤로 재생목록이 추가 로딩되어도 자동으로 필터 재적용
- 유튜브의 다크/라이트 테마에 맞춰 자동으로 스타일 적용

## 설치 방법 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력 후 이동
2. 우측 상단의 "개발자 모드"를 켭니다
3. "압축해제된 확장 프로그램을 로드합니다" 버튼 클릭
4. 이 저장소 폴더(`youtube1`)를 선택
5. 유튜브 재생목록 페이지로 이동하면 검색창이 자동으로 나타납니다

## 폴더 구조

```
manifest.json   - 확장 프로그램 설정 (Manifest V3)
content.js      - 재생목록 페이지 감지 및 검색 기능 구현
content.css     - 검색창 스타일
icons/          - 확장 프로그램 아이콘
```
